# Cuidado de Plantas

App Android (Kotlin + Jetpack Compose) del Proyecto Unidad 3: registro, login y CRUD de plantas.

Arquitectura: MVVM + Repository + DTO + Mapper + inyección de dependencias manual (`AppContainer`).
Estructura basada en el repositorio guía `kt_p4a` (feature `jsonplaceholder`).

## Backend y documentación

- API local en `backend/` (Node 20+, sin dependencias): `cd backend && npm start`.
- Contrato, modelo de datos y validaciones: [`docs/API.md`](docs/API.md).
- Usuario de demostración: `demo@plantas.com` / `plantas123`.
